# AI filters for English text

Reference list for the skill. Literal uses are fine ("a medieval tapestry", "navigate the menu"). Flag figurative ones.

## Verbs

| Avoid | Use |
|---|---|
| delve (into), dive into | look at, cover |
| leverage, harness, utilize | use |
| facilitate, enable (vague) | help, let |
| foster, cultivate, nurture (figurative) | encourage, build |
| bolster, reinforce | support, strengthen |
| underscore, highlight, emphasize | show, say (or cut) |
| unveil, unlock, unleash | show, release, get |
| navigate (figurative) | handle, deal with |
| streamline, optimize | simplify, speed up |
| elevate, empower, supercharge | improve |
| enhance | improve |
| endeavor, ascertain, elucidate | try, find out, explain |
| embark on | start |
| serves as, stands as, functions as | is |
| boasts, features, offers | has |
| garner | get |
| resonate (with) | appeal to |
